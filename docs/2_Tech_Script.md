# Технический Сценарий (Для Оператора)

**Роль:** Оператор (за ноутбуком).
**Оборудование:** Макбук, Проектор, Аудио-выход, Пульт от гирлянд (или связь с осветителем).

| Этап | Слайд / Видео (Экран) | Аудио (Звук) | Свет / Действие |
| :--- | :--- | :--- | :--- |
| **0. Сбор** | Слайд 1: Заставка "Рождество в доме Энди" | Фоновая музыка: Jingle Bells (Тихо) | Полный свет |
| **1. Штаб** | Слайд 2: Логотип "История Игрушек" | - | Свет в коридоре вкл. |
| **2. Драма** | Слайд 3: Интерьер комнаты Энди (День) | - | - |
| **2. Уход** | - | **ЗВУК:** Скрип двери, Ключ в замке | - |
| **3. Коридор** | Слайд 4: Статика / Помехи | - | - |
| **3. Лазер** | **ВИДЕО:** Лотсо (Помехи -> Лотсо говорит) | Голос Лотсо (из видео) | - |
| **3. Ошибка** | **ВИДЕО:** Красная тревога / Сирена | **ЗВУК:** Громкая Сирена (5 сек) | Мигание (если есть) |
| **3. Победа** | Слайд 5: Зеленый доступ / Открытый замок | **ЗВУК:** "Пшшш" (Отключение лазеров) | - |
| **4. Пес** | **ВИДЕО 1:** Спящий пес Скуд (Цикл) | **ЗВУК 1:** Громкий Храп (Цикл) | Приглушить свет |
| **4. Лай** | **ВИДЕО 2:** Лающий пес Скуд | **ЗВУК 2:** РЕЗКИЙ Лай собаки | - |
| **4. Прыжки** | Слайд 6: Силуэт 1 (Поза) | Фоновая: Мистическая/Напряженная | Тускнеют гирлянды (50%) |
| **...** | Слайд 7: Силуэт 2 (Поза) | - | Тускнеют гирлянды (40%) |
| **...** | Слайд 8: Силуэт 3 (Поза) | - | Тускнеют гирлянды (30%) |
| **5. Логово** | **ВИДЕО:** Злой Лотсо (Финал) | Голос Лотсо | Почти темнота + УФ |
| **5. Сейф** | Слайд 9: Закрытый сейф | - | Только УФ фонари |
| **5. ФИНАЛ** | Слайд 10: Открытый сейф + Свет | **ЗВУК:** Щелчок замка + Фанфары (Тихо) | - |
| **5. Энди** | Слайд 11: Вертеп с Младенцем | **ЗВУК:** Ключ в двери (Возвращение) | Включить полный свет |
| **5. История** | Слайд 12: Фото церкви в Таразе | - | - |
| **5. Конец** | Слайд 13: С Рождеством! | **МУЗЫКА:** "You've Got a Friend in Me" (Громко) | - |

**Важные заметки:**
1.  **Сирена:** Включать ТОЛЬКО по визуальному сигналу "кто-то задел нитку".
2.  **Лай:** Включать, когда ведущий подает знак (или когда музыка стихает).
3.  **Гирлянды:** Плавно гасить во время "Теневых прыжков".
