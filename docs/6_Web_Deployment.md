# Руководство по развертыванию сайта (Buzz Soundboard)

Это руководство поможет вам запустить сайт со звуками Базза Лайтера на вашем сервере **Obama Ubuntu** (или любом другом Linux сервере).

## Шаг 1: Подготовка файлов

Перед загрузкой на сервер, убедитесь, что у вас есть следующая структура папок на вашем компьютере:

```text
/site/
├── buzz_sounds.html  <-- Файл, который я создал
└── sounds/           <-- Эту папку нужно СОЗДАТЬ САМИМ
    ├── laser.mp3
    ├── infinity.mp3
    ├── command.mp3
    ├── scan.mp3
    ├── alert.mp3
    └── welcome.mp3
```

> **Где взять звуки?** 
> Вы можете скачать их из интернета или сгенерировать. Названия файлов должны *точно* совпадать (маленькие буквы, .mp3).

---

## Шаг 2: Настройка сервера (Ubuntu)

Вам нужно установить простой веб-сервер. Мы используем **Nginx**, так как он надежный и простой.

**1. Подключитесь к серверу:**
```bash
ssh user@your-server-ip
```

**2. Обновите систему и установите Nginx:**
```bash
sudo apt update
sudo apt install nginx -y
```

**3. Проверьте, работает ли он:**
Откройте в браузере IP вашего сервера (например, `http://123.45.67.89`). Вы должны увидеть надпись "Welcome to nginx!".

---

## Шаг 3: Загрузка файлов

Мы разместим сайт в стандартной папке `/var/www/html`.

**Вариант А: Использование команды `scp` (с вашего компьютера)**
В терминале ВАШЕГО компьютера (не сервера) выполните:
```bash
# Загружаем файл HTML
scp /путь/к/site/buzz_sounds.html user@your-server-ip:/tmp/index.html

# Загружаем папку sounds (рекурсивно)
scp -r /путь/к/site/sounds user@your-server-ip:/tmp/sounds
```
*Замените `user@your-server-ip` на ваши данные.*

**Вариант Б: Если `scp` сложно**
Вы можете использовать программу **FileZilla** или **WinSCP**.
1. Подключитесь к серверу (SFTP).
2. Перейдите в папку `/var/www/html`.
3. Просто перетащите туда файл `buzz_sounds.html` (переименуйте его в `index.html`) и папку `sounds`.

---

## Шаг 4: Финальная настройка

Вернитесь в терминал СЕРВЕРА. Переместим файлы из `/tmp` в рабочую папку веб-сервера.

```bash
# Удаляем старую приветственную страницу
sudo rm /var/www/html/index.nginx-debian.html
sudo rm /var/www/html/index.html

# Перемещаем наши файлы
sudo mv /tmp/index.html /var/www/html/index.html
sudo mv /tmp/sounds /var/www/html/sounds

# Исправляем права доступа (чтобы Nginx мог их читать)
sudo chown -R www-data:www-data /var/www/html
sudo chmod -R 755 /var/www/html
```

---

## Шаг 5: Проверка

1. Откройте в браузере (на телефоне или компьютере): `http://ВАШ_IP_АДРЕС`
2. Вы должны увидеть панель Базза.
3. Нажмите на кнопки. Если звуки не играют:
   - Проверьте, что папка `sounds` существует (`ls /var/www/html/sounds`).
   - Проверьте названия файлов (Linux чувствителен к регистру! `Laser.mp3` не сработает, нужно `laser.mp3`).

## Альтернатива: Быстрый запуск (Python)
Если вы не хотите устанавливать Nginx, можно запустить временный сервер одной командой:
1. Загрузите файлы в любую папку.
2. Зайдите в эту папку.
3. Запустите: `python3 -m http.server 80`
4. Сайт будет доступен по вашему IP.
