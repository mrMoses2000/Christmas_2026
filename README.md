# Проект: Рождество 2026

Добро пожаловать в пакет документации операции «Спасти Рождество».

## 📂 Навигация по файлам

Все документы находятся в папке `docs/`. Если вам трудно читать их в сыром виде, попробуйте открыть их через **«Предварительный просмотр»** (Preview) в вашем редакторе (VS Code, Obsidian) или скопировать текст в Google Docs.

### Главные Сценарии
1.  **[Полный Сценарий (Master Scenario)](docs/1_Master_Scenario.md)**
    *   *Это самый важный файл.* Здесь весь сюжет от начала до конца, все диалоги и действия.
    *   **Для кого:** Режиссер, Организатор.

2.  **[Технический Скрипт (Tech Script)](docs/2_Tech_Script.md)**
    *   Таблица только с действиями для оператора (когда включать музыку, слайды, свет).
    *   **Для кого:** Звуковик, Световик, Оператор ноутбука.

3.  **[Роли для Актеров (Roles)](docs/3_Roles_and_Briefing.md)**
    *   Краткие памятки для каждого персонажа (Вуди, Базз, Рекс и т.д.).
    *   **Для кого:** Распечатать и раздать актерам.

### Организация
4.  **[Реквизит и Логистика (Setup)](docs/4_Logistics_Setup.md)**
    *   Что купить, что приготовить, как расставить мебель в комнатах.
    *   **Для кого:** Завхоз, Помощники.

5.  **[Медиа и Видео (Prompts)](docs/5_Media_Prompts.md)**
    *   Описание того, какие видео нужно сгенерировать (Лотсо, Собака) и промпты для нейросетей.
    *   **Для кого:** Контент-мейкер.

### Сайт (Звуковая панель Базза)
6.  **[Руководство по запуску сайта](docs/6_Web_Deployment.md)**
    *   Инструкция, как запустить `site/buzz_sounds.html` на вашем сервере Ubuntu.

---

## 🚀 Как пользоваться?

1.  **Распечатка:** Откройте файлы `1_Master_Scenario.md` и `3_Roles_and_Briefing.md`, скопируйте текст в Word/Google Docs, отформатируйте шрифт покрупнее и распечатайте.
2.  **Чтение с экрана:** Используйте режим "Preview" (Значок лупы или книжки в редакторе).
3.  **Сайт:** Следуйте инструкции №6, чтобы Базз мог включать звуки с телефона.
